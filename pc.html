사용 안내

  • 보기 — 101~106동 배치표를 한 줄에 나란히 봅니다. 맞춤을 누르면 6개 동이 현재 창에 꼭 들어오고, + / −로 확대·축소할 수 있습니다. 설정은 기억됩니다.
  • 호실 더블클릭(폰은 한 번 탭) → 호실 바로 옆에 작은 메모장이 뜹니다. 타입·면적·분양가·계약금(5%) 확인, 색상 변경, 메모 작성.
  • 색상 — 기본(미확인) · 매매 · 전세 · 월세 · 보류·매매완료. 메모만 적어도 색은 바뀌지 않습니다.
  • 급매 (급) — 메모나 금액에 급매(급내)라고 적으면 호실 숫자 옆에 빨간 (급)이 붙습니다. 메모장의 (급) 급매 표시 버튼으로 직접 켜고 끌 수도 있고, 상단 급매 필터로 모아 볼 수 있습니다.
  • 입력 칸 — 매매·기본·보류·완료는 금액·소유주·연락처, 전세·월세는 임대 금액·임대인·임차인과 연락처를 적습니다. 적은 값은 툴팁과 검색에도 바로 잡힙니다.
  • 메모장은 × 버튼·Esc·바깥 클릭으로 닫히고, 폰에서는 화면 가운데 카드로 뜹니다.
  • 마우스를 올리면 분양가·면적(㎡·평)·현재 상태·메모 요약이 툴팁으로 보입니다.
  • 26.11 엑셀 매물은 기본 데이터로 들어 있어 처음 열어도 바로 표시되고, 이후 수정·추가는 이 브라우저에 자동 저장됩니다.
  • 단축키 — F 맞춤 · 0 100% · + / − 확대·축소 · / 검색 · Esc 닫기
  • PC ↔ 폰 이동이나 백업은 JSON 내보내기 → JSON 불러오기로 하세요.
  • 휴대폰에서는 상단 📱 모바일 보기를 누르면 동별로 세로로 넘기며 보기 편합니다. (모바일판에서 PC 보기로 돌아올 수 있습니다)
  • 비밀번호는 따로 안내받은 번호를 넣고, 이 기기에 기억하기를 켜 두면 다음부터는 묻지 않고 열립니다. 🔒 잠금을 누르면 다시 잠깁니다.
  • 새 매물이 올라오면 같은 주소를 새로고침만 해도 최신 내용으로 바뀜니다. 이 브라우저에서 직접 적은 메모·색은 그대로 남습니다.
